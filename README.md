# Jogo da Forca

Projeto desenvolvido em Java como prática de lógica de programação e fundamentos da linguagem.

## Sobre o projeto

O programa consiste em um jogo da forca executado no console, onde uma palavra é selecionada aleatoriamente e o jogador deve descobri-la utilizando tentativas de letras.

## Funcionalidades

- Seleção aleatória de palavras
- Sistema de 6 tentativas
- Validação de entrada
- Verificação de letras repetidas
- Exibição das letras descobertas
- Sistema de vitória e derrota

## Tecnologias utilizadas

- Java
- ArrayList
- Scanner
- Random

## Conceitos praticados

- Estruturas de repetição
- Estruturas condicionais
- Manipulação de `String` e `char`
- Coleções
- Variáveis booleanas
- Validação de dados
- Controle de fluxo
